# Airline Delay Clustering Analysis

This project analyses aggregated U.S. airline-delay data from January 2022 to August 2023, focusing on the 15 busiest airports.

The notebook includes:

* Exploratory data analysis
* Delay analysis by carrier, airport, month, and cause
* Feature engineering and data standardisation
* K-Means and hierarchical clustering
* PCA visualisation
* Cluster evaluation using Silhouette and Davies-Bouldin scores


## Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and SciPy.

## How to Run

1. Open the notebook in Google Colab.
2. Add the airline-delay CSV file to Google Drive.
3. Update `DATA_PATH` if necessary.
4. Select **Runtime → Run all**.

The dataset is not included in this repository. You can find it on Kaggle.
